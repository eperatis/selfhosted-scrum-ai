        LLM API

        HTTP endpoints at . This port can read and create boards and tickets, but can't change or delete anything; the board itself runs on a different port.

        GET /api/boards
        Every board's id, name, ticket count per column and number of blocked tickets
        GET /api/boards/{id}
        One board's tickets, with comments and a blocked flag
        POST /api/boards
        Create a board: {"name"}
        POST /api/boards/{id}/tickets
        Create a ticket: {"title", "desc", "column", "dueDate", "blockedBy"}, only title required
